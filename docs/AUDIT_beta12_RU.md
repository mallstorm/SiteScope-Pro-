# Аудит SiteScope Pro (beta12) и план исправлений

Дата: 2026-11-13. Ветка `redesign`. Метод: статический разбор кода и документации, CI (тесты + Lint). Запуск на физическом устройстве в этом аудите **не выполнялся**.

## 0. Главное расхождение: правок Codex по «RouterScan 2.60» в репозитории нет

В `mallstorm/SiteScope-Pro-` нет коммитов, веток, файлов и текста, относящихся к RouterScan или к «10 этапам» Codex; история ветки `redesign` состоит из коммитов автора и этой сессии. Поэтому проверить эти правки нельзя. Чтобы их проверить, нужно запушить ветку/файлы Codex в репозиторий (или приложить diff). Отдельно: функции RouterScan, которые подбирают пароли и извлекают учётные данные чужих роутеров, **не реализуются** — это противоречит `docs/08_AUTHORIZED_SCANNER_RU.md` (только TCP-проверка, без подбора и эксплуатации) и политике приложения.

## 2. Что добавлено в beta24

- **Скорость как в Ookla Speedtest** (`net/SpeedEngine.kt`, `SpeedScreen.kt`): спидометр с нелинейной шкалой, задержка/джиттер/потери, задержка под нагрузкой, скачивание и отдача в несколько потоков с «живой» скоростью, пик, серверы (Cloudflare, Tele2, Hetzner, OVH, свой), настройки (что измерять, единицы Мбит/с · МБ/с · кбит/с, длительность, потоки, число пингов, лимит трафика), история и «поделиться». Старая проверка «скачать/отправить файл» удалена.
- **Поиск потоков по маске** (`tv/MaskSearch.kt`, `MaskSearchScreen.kt`): `%d`, `%d{a-b}`, `%03d`, `(a|b|c)`, `(.*)`, `channel_name`, `xxx.xxx.xxx.xxx`, `yyyyy`; перебор с лимитом, параллельностью, быстрой отсечкой мёртвых host:port; http/https — полная проверка потока, rtsp — DESCRIBE, rtmp/mms — проверка порта. Окно вверху: квадрат с кадром из потока (или логотип из ваших каналов) и распознанное название. Название берётся из служебных таблиц потока (SDT), затем из маски; известные каналы приводятся к виду «1+1», «Интер», «НТВ», «РЕН ТВ». Вход: «Ещё → Поиск ТВ по маске», раздел «ТВ в локальной сети» и «Добавить плейлист».
- Тесты: `MaskSearchTest` (перебор, диапазоны, нули, альтернативы, `(.*)`, названия, IP/порты, распознавание).

## 3. Ограничения (честно)

- Распознавание названия по картинке (OCR логотипа) **не включено**: офлайн-модель ML Kit не поддерживает кириллицу, а Tesseract потребует загрузки языковых данных. Сейчас кадр показывается человеку, а название определяется по данным потока и маске.
- `udp://` и `rtp://` без подписки на группу проверить нельзя — такие комбинации пропускаются.
- Серверы Tele2/Hetzner/OVH — публичные тестовые файлы; их доступность не гарантируется (Cloudflare — основной).
- Сборка и тесты проверяются только в CI; устройства для проверки не было.
