# Этап 32 — VNC, SNMP, MQTT, ONVIF и DLNA

## VNC
Basic RFB 3.8 viewer with raw framebuffer, touch pointer, keyboard events and classic VNC authentication.

## SNMP
Read-only v1/v2c GET and bounded WALK. SET is excluded.

## MQTT
MQTT 3.1.1 TCP/TLS, manual connect, subscribe and QoS0 publish.

## ONVIF
WS-Security read-only device information, profiles and stream URI.

## DLNA
UPnP ContentDirectory discovery and BrowseDirectChildren navigation.

## External fallback
RDP and SMB remain routed to compatible installed applications until full audited native stacks are integrated.
