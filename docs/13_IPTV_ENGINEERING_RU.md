# 13. IPTV Engineering — спецификация alpha3

## Назначение

Модуль предназначен для владельца IPTV-сети, оператора, системного администратора или инженера, имеющего явное разрешение на диагностику.

## Источники каталога каналов

1. M3U/M3U8:
   - `#EXTINF`;
   - `tvg-id`;
   - `tvg-name`;
   - `tvg-logo`;
   - `group-title`;
   - `#EXTGRP`;
   - HTTP, HTTPS, UDP multicast и RTP multicast URL.
2. XMLTV:
   - сопоставление по `channel id`;
   - `display-name`;
   - `icon src`.
3. SAP/SDP:
   - локальные анонсы на `224.2.127.254:9875`;
   - имя сессии;
   - multicast IP и media port;
   - дополнительные атрибуты группы и логотипа, если отправитель их публикует.
4. MPEG-TS:
   - PAT;
   - PMT;
   - DVB-SDT;
   - имя сервиса;
   - имя провайдера;
   - основной видео- и аудиокодек.

## udpxy

Поддерживаются запросы:

- `http://host:port/udp/239.x.x.x:port`;
- `http://host:port/rtp/239.x.x.x:port`.

Поиск выполняется по status page `/status/`, `/status` и корневой странице. Endpoint считается подтверждённым только при наличии сигнатуры udpxy/UDP-to-HTTP relay.

## Карточка канала

- зелёная отметка доступного потока;
- название;
- группа;
- логотип;
- source URL;
- playback URL;
- тип источника;
- статус;
- контейнер;
- MPEG-TS/DVB service name;
- provider name;
- видео- и аудиокодек;
- задержка подключения;
- приблизительный bitrate выборки;
- доказательство определения;
- текст ошибки.

## Просмотр

Встроенный просмотр использует Android `VideoView`/`MediaPlayer`. Доступна передача URL внешнему плееру. Фактическая поддержка конкретного кодека зависит от аппаратных и системных декодеров устройства.

## Ограничения, которые невозможно устранить только сканером

- udpxy не является каталогом каналов и не знает все существующие multicast-группы;
- логотип обычно не передаётся внутри MPEG-TS;
- название может отсутствовать, если оператор не передаёт DVB-SDT и не предоставил M3U/XMLTV;
- закрытые и DRM-потоки не открываются без штатной авторизации;
- обычное Android-приложение не может пассивно перехватывать весь IGMP-трафик сети без системных привилегий;
- перебор всего multicast-диапазона намеренно не реализован.
