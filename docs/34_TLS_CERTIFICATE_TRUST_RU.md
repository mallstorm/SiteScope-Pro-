# TLS Certificate Trust — безопасный режим Web Client

## Назначение
Обеспечить доступ к разрешённым административным HTTPS-интерфейсам, которые используют самоподписанный сертификат, сертификат частного CA или сертификат, выпущенный на DNS-имя при открытии по IP.

## Сценарии

### Продолжить один раз
Сертификат не сохраняется. Разрешение действует только для текущей загрузки WebView.

### Доверять сертификату
Сохраняется SHA-256 для точного `host:port`. Другой сертификат, адрес или порт не получает доверие.

### Сертификат изменился
Соединение блокируется. Пользователь видит оба отпечатка и принимает отдельное решение.

### Ошибка даты
Постоянное закрепление запрещено для:
- истёкшего сертификата;
- сертификата, который ещё не действует;
- некорректной даты.

## Что не реализуется
- глобальное `trust all`;
- отключение hostname/certificate verification для всех узлов;
- автоматическое принятие нового сертификата;
- перенос TLS-pin в backup как универсального доверия.

## Рекомендованная проверка
1. Сверить SHA-256 отпечаток с владельцем или панелью сервера.
2. Для разовой диагностики выбрать `Продолжить один раз`.
3. Для собственного стабильного устройства выбрать `Доверять этому сертификату`.
4. При предупреждении о смене сертификата не продолжать, пока причина изменения не подтверждена.
