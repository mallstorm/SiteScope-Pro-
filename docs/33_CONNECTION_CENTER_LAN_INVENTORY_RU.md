# Спецификация 33 — Connection Center 2.0 и LAN Inventory

## Connection Center
Экран содержит две вкладки:
1. `Сохранённые` — профили, поиск, проверка, открытие и редактирование.
2. `Журнал` — запуски клиентов и результаты health-check.

## Статусы
- `доступен` — endpoint ответил на HTTP/TCP-проверку;
- `недоступен` — соединение не установлено в пределах таймаута;
- `в клиенте` — UDP-протокол требует специализированного запроса;
- `не проверен` — health-check ещё не выполнялся.

## LAN Inventory
Каждый успешный LAN Discovery создаёт снимок. Сервисы одного IP объединяются в карточку устройства. Сравнение выполняется по IP между двумя последними снимками.

## Безопасность
Health-check не выполняет авторизацию и не отправляет команды. LAN Discovery использует только read-only SSDP, ONVIF WS-Discovery и mDNS/DNS-SD.
