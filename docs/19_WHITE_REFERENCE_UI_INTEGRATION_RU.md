# Спецификация 19 — интеграция белого UI-референса

## Концепция
Интерфейс SiteScope Pro должен иметь:
- белую общую атмосферу;
- ровные ряды плиток;
- светло-бежевые плитки;
- корректные вертикальные и горизонтальные интервалы;
- простые, незатейливые, но понятные иконки.

## Применение
### Главный экран
- 2 колонки плиток;
- центрированные иконки;
- читаемые заголовки плиток;
- минимум визуального шума.

### Вторичные экраны
- белый фон;
- бежевые карточки;
- простые иконки в заголовках секций;
- сохранение инженерной информативности.

## Ограничения
- без тяжёлых внешних UI-фреймворков;
- полная совместимость с офлайн-сборкой;
- без нарушения текущей логики навигации.
