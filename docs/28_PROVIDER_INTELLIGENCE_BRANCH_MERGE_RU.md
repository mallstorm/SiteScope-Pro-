# Спецификация 28 — перенос ветки «Как найти диапазон IP»

## Место в интерфейсе

```text
Главное → IP Engineering → IP Intelligence → IP / ASN
```

Provider Intelligence является отдельной панелью и не дублирует TCP-сканер.

## Сценарий 1 — мой провайдер

1. Определить транспорт Android.
2. Проверить наличие VPN.
3. Получить внешний IPv4.
4. Попытаться получить IPv6.
5. Для каждого адреса получить BGP-префикс и origin ASN.
6. Получить holder и announced prefixes.
7. Выделить диапазон, содержащий текущий IP.
8. Позволить копировать CIDR и экспортировать CSV.

## Сценарий 2 — поиск провайдера

Ввод допускает:

- бренд;
- юридическое имя;
- ASN;
- русское, украинское или английское написание.

Источники:

- RIPE Database REST search;
- inverse organisation → aut-num;
- RIPEstat Network Info;
- RIPEstat AS Overview;
- RIPEstat Announced Prefixes;
- api.ipify.org / api6.ipify.org.

## Правила качества

- известный alias — только подсказка;
- префиксы всегда перепроверяются онлайн;
- одноимённые организации не объединяются автоматически;
- отсутствие IPv6 не является ошибкой;
- при VPN результат подписывается как провайдер VPN-выхода;
- IPv4 и IPv6 рассчитываются через BigInteger;
- запросы Provider Intelligence работают только по HTTPS.
