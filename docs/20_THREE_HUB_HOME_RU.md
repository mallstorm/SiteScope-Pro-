# Спецификация 20 — главный экран из трёх центров системы

## Принцип
Главный экран SiteScope Pro должен показывать не разрозненные функции, а крупные пользовательские направления работы.

## Итоговая структура
### 1. SEO-аудит
Включает:
- технический SEO-аудит;
- PageSpeed / Core Web Vitals;
- поисковые метрики;
- контент и структура.

### 2. IP Инжинеринг
Включает:
- домен и IP;
- DNS / HTTP / TLS;
- сканер портов;
- LAN discovery.

### 3. IPTV Инжинеринг
Включает:
- multicast;
- udpxy;
- M3U/XMLTV;
- потоковый анализ и просмотр.

## UI-требования
- общий фон — белый;
- плитки — мягко-бежевые;
- крупные цветные иконки;
- вертикальные интервалы между плитками;
- `Проекты` и `История` не дублируются на главной.
