# Спецификация 25 — центрированная видеосцена IPTV-плеера

## Требование
Видео должно выглядеть как в обычном медиаплеере:
- кадр находится по центру;
- пропорции сохраняются;
- свободная область заполняется чёрным цветом;
- видео не прижимается к верхнему краю;
- поток не растягивается.

## Алгоритм
1. До подготовки потока использовать 16:9.
2. Получить фактические размеры видео.
3. Вычислить максимальный прямоугольник, помещающийся внутри окна.
4. Установить контейнеру рассчитанные ширину и высоту.
5. Разместить контейнер через `Gravity.CENTER`.
6. Повторять расчёт при изменении размеров и полноэкранного режима.
