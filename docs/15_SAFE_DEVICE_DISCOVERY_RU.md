# Безопасное обнаружение сетевых устройств

## Назначение

Модуль предназначен для инвентаризации собственной или явно разрешённой локальной сети. Он использует только стандартизированные discovery-запросы и публично передаваемые метаданные.

## Поддерживаемые механизмы

- SSDP/UPnP M-SEARCH.
- ONVIF WS-Discovery Probe.
- mDNS/DNS-SD PTR discovery.
- TCP banner/protocol fingerprints из инженерного сканера.
- PTR, TLS subject и HTTP metadata.

## Карточка ресурса

Каждая карточка содержит IP, порт, протокол обнаружения, тип устройства, имя, manufacturer/server, model/hardware, endpoint, сервисы, доказательство и confidence.

## Запрещённые функции

Не реализуются подбор учётных данных, WPS/Pixie Dust, обход авторизации, RCE, credential stuffing, извлечение Wi-Fi-паролей и глобальный поиск чужих устройств.
