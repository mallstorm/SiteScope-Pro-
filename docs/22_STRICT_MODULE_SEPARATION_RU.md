# Спецификация 22 — строгая изоляция модулей

## Правила
1. Главная содержит только три входа: SEO, IP и IPTV.
2. SEO не показывает IP-сканер или IPTV.
3. IP не показывает SEO-метрики или IPTV-каталог.
4. IPTV не показывает обычный SEO-аудит или универсальный IP-сканер.
5. Проект принадлежит ровно одному типу: SEO, IP или IPTV.
6. История фильтруется по этим же типам.
7. Подфункции не дублируются на главной и в нижнем меню.
