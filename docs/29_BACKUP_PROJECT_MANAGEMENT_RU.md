# Спецификация 29 — Backup, миграция и управление проектами

## Назначение
Обеспечить перенос пользовательских данных между переустановками и дать каждому проекту полноценный жизненный цикл.

## Формат backup
- JSON UTF-8;
- идентификатор `SiteScopeProBackup`;
- версия схемы;
- дата создания;
- версия приложения;
- статистика содержимого;
- типизированные значения SharedPreferences.

## Переносимые разделы
- `sitescope_data_v1`;
- `sitescope_iptv`;
- `ip_intelligence`;
- `sitescope_settings_v1`.

## Исключения
- secure storage;
- DB-IP SQLite;
- активное сканирование;
- системный кэш и временные файлы.

## Проекты
Проект принадлежит одному типу: SEO, IP или IPTV.

Метаданные:
- название;
- цель;
- краткий результат;
- заметки;
- теги;
- закрепление;
- архив;
- дата изменения.

## UX
- обычное нажатие открывает проект;
- долгое нажатие открывает меню управления;
- архив не отображается в активных фильтрах;
- закреплённые элементы расположены выше остальных;
- удаление требует подтверждения.
