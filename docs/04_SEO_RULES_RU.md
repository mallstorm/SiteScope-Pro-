# Каталог SEO-правил 0.1.0

Каждая проблема содержит `code`, `severity`, `title`, `why`, `evidence`, `recommendation` и `affected_url`.

## Реализованные группы
- HTTP/HTTPS и status codes;
- redirect chain;
- title и description;
- H1 и иерархия headings;
- canonical;
- meta robots;
- изображения без alt;
- внутренние битые ссылки по результатам crawl;
- security headers;
- lang и viewport;
- content volume;
- robots.txt и sitemap discovery.

Правила не обещают изменение позиций и не выдают эвристику за данные поисковых систем.
