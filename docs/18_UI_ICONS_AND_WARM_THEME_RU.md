# Спецификация 18 — UI-иконки и тёплая тема

## Цель
Сделать интерфейс SiteScope Pro менее сухим и более наглядным без перехода на тяжёлую дизайн-систему.

## Реализация
1. Для каждой основной плитки добавлена простая визуальная иконка.
2. Цвет поверхности карточек изменён с белого на мягкий бежевый.
3. Исправлены интервалы между плитками на главном экране.
4. Нижняя навигация дополнена иконками.

## Принципы
- Никаких сложных зависимостей и внешних UI-библиотек.
- Вся реализация остаётся совместимой с прямой офлайн-сборкой.
- Улучшения не должны ломать существующую логику навигации.
