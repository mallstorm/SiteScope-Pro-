# Спецификация 26 — IP Intelligence Center

## Цель

Дополнить раздел **IP Engineering** профессиональным центром пассивной IP-разведки и каталогом сетевых диапазонов. Модуль разработан после анализа `suip.biz` и `ip.osnova.news`, но не зависит от HTML этих сайтов и не копирует их данные.

## Что показал анализ референсов

### suip.biz
Полезное ядро IP-раздела:

- диапазоны по стране;
- диапазоны по континенту;
- диапазоны по региону и городу;
- диапазоны ISP/провайдера;
- диапазоны автономной системы;
- поиск организации и сетевого оператора;
- геолокация IPv4/IPv6;
- ASN по IP;
- reverse DNS;
- преобразование диапазона в CIDR;
- агрегация диапазонов;
- CIDR в начало/конец;
- IPv4/IPv6-калькуляторы;
- конвертация IP в decimal/hex/binary;
- раскрытие IPv6.

На сайте также есть много инструментов, не относящихся к IP Intelligence: социальный OSINT, обход защит, поиск скрытых origin-IP, уязвимости, SQL injection, веб-сканеры и другие атакующие функции. Они не включены в новый модуль.

### ip.osnova.news
Полезное ядро:

- карточка IP;
- страна, регион, город и координаты;
- ISP, организация и ASN;
- сеть/диапазон;
- WHOIS;
- карта;
- каталоги стран;
- страницы регионов и городов;
- списки провайдеров территории;
- диапазоны провайдера.

Данные референса не используются напрямую: на публичных страницах встречаются устаревшие или редакционно изменённые географические подписи. SiteScope Pro формирует результаты из RIPEstat/RDAP и импортируемых DB-IP-баз.

## Архитектура

IP Intelligence является отдельным экраном внутри IP Engineering и не смешивается с TCP-сканером.

### Вкладки

1. **IP / ASN**
2. **Каталог**

## 1. IP / ASN

Входные значения:

- IPv4;
- IPv6;
- IP-префикс;
- домен;
- ASN.

Результат:

- разрешение домена в IP;
- содержащий маршрутизируемый префикс;
- announcing ASN;
- организация/holder;
- статус анонса;
- RIR;
- RDAP handle и название;
- WHOIS;
- abuse-контакты;
- reverse DNS;
- страна, регион, город и координаты;
- локальный диапазон DB-IP;
- CIDR локального диапазона;
- список анонсируемых префиксов ASN;
- открытие приблизительной точки на карте;
- локальная история последних запросов;
- текстовый экспорт.

Онлайн-источники:

- RIPEstat Network Info;
- Prefix Overview;
- AS Overview;
- Announced Prefixes;
- WHOIS;
- Abuse Contact Finder;
- Reverse DNS IP;
- MaxMind GeoLite через RIPEstat;
- RDAP bootstrap через `rdap.org`.

## 2. Каталог

Иерархия фильтров:

```text
Континент → Страна → Регион → Город → Провайдер / ASN
```

### Диапазоны страны

Работают без локальной базы через RIPEstat Country Resource List:

- ASN страны;
- IPv4-префиксы;
- IPv6-префиксы;
- полный экспорт результата.

Выбор страны доступен из встроенного ISO-справочника даже до загрузки DB-IP.

### Регион и город

После импорта City Lite:

- список стран;
- список регионов выбранной страны;
- список городов выбранного региона;
- фильтр по тексту;
- IPv4 и IPv6 диапазоны;
- координаты;
- сопоставленный ASN/провайдер;
- преобразование диапазона в минимальный набор CIDR;
- постраничный вывод по 500 записей;
- CSV-экспорт.

### Провайдеры территории

При наличии City Lite и ASN Lite:

- сопоставление диапазонов территории с ASN;
- список провайдеров/организаций;
- количество совпавших диапазонов в выборке;
- переход к ASN;
- экспорт CSV.

Для очень больших территорий список провайдеров является выборкой первых 2500 географических блоков и не позиционируется как абсолютный рейтинг.

### Диапазоны провайдера / ASN

- поиск по номеру ASN;
- поиск по части названия организации;
- локальные диапазоны ASN Lite;
- онлайн-анонсируемые префиксы RIPEstat;
- IPv4 и IPv6;
- экспорт.

## 3. База

### DB-IP City Lite

Используется для:

- континента;
- страны;
- региона/области;
- города;
- широты и долготы;
- диапазонов IPv4/IPv6.

### DB-IP ASN Lite

Используется для:

- ASN;
- организации;
- диапазонов IPv4/IPv6;
- поиска провайдера по названию.

### Управление

- автоматический поиск текущего ежемесячного релиза;
- fallback на три предыдущих месяца;
- загрузка CSV.GZ напрямую в закрытое хранилище приложения;
- импорт собственного CSV/CSV.GZ через Android Storage Access Framework;
- потоковая распаковка GZIP;
- RFC4180 CSV parser;
- пакетные SQLite-транзакции;
- временное отключение индексов на время массового импорта;
- повторное построение индексов;
- прогресс и отмена;
- проверка свободного места;
- отдельное удаление City и ASN индекса;
- статус числа импортированных диапазонов и версии источника.

### Размер

City Lite содержит миллионы диапазонов и может потребовать несколько гигабайт для сжатого файла, SQLite-таблицы и индексов. Перед автоматической загрузкой приложение требует около 3 ГБ свободного места.

### Лицензия

В интерфейсе отображается обязательная атрибуция:

`IP Geolocation by DB-IP (db-ip.com), CC BY 4.0`

## 4. Калькуляторы

### CIDR / подсеть

- сеть;
- начало и конец;
- количество адресов;
- IPv4-маска;
- usable hosts и broadcast;
- IPv6-префиксы.

### Диапазон → CIDR

- IPv4;
- IPv6;
- минимальный набор CIDR.

### Агрегация

- несколько CIDR и диапазонов;
- объединение пересекающихся и соседних блоков;
- повторная минимизация в CIDR.

### Конвертер

- IP → decimal;
- decimal → IP;
- IP → hexadecimal;
- hexadecimal → IP;
- IP → binary.

### IPv6

- expand;
- compress.

## Границы точности

- Геолокация IP не является точным местонахождением человека или устройства.
- Координаты могут указывать на узел, POP, административный центр или зарегистрированное местонахождение провайдера.
- Страна регистрации ресурса, страна маршрутизации и физическая территория использования могут отличаться.
- ASN Lite предоставляет организацию автономной системы, а не полный коммерческий ISP-профиль.
- Интернет-источники могут временно быть недоступны; локальные функции продолжают работать после импорта базы.

---

## Безопасность

IP Intelligence выполняет пассивные справочные запросы. Он не запускает:

- эксплуатацию уязвимостей;
- brute force;
- обход WAF/CDN;
- поиск скрытого origin-IP;
- SQL injection;
- скрытое или spoofed-сканирование.

TCP-сканер остаётся отдельным инструментом IP Engineering и требует подтверждения права на исследование сети.
