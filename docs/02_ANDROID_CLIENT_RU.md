# Android-клиент

## Экраны
- Главная: универсальный ввод URL.
- Проекты: список сайтов и состояние аудита.
- Аудит: сводка, оценки и проблемы.
- Сеть: зарезервировано для этапа 7.
- История: предыдущие запуски.

## Технологии
Kotlin, Compose, Navigation, ViewModel, Retrofit, Room, Hilt.

## UX-принципы
- русский интерфейс по умолчанию;
- отсутствие WebView;
- понятный статус незапущенных интеграций;
- источник и confidence возле внешних метрик;
- никакой подмены отсутствующих данных.
