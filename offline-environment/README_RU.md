# SiteScope Pro Offline Environment

Исходные пять томов APKForge найдены по манифесту, но бинарные ZIP не были смонтированы File Library. Текущий каталог содержит проект, JDK-ссылку и скрипты прямой сборки. Для полной APK-сборки необходимы android.jar, aapt2, d8/r8, zipalign и apksigner из исходных томов либо официальных prebuilts.
