# Прямой UDP/RTP multicast на Android

## Цель

Приложение должно принимать операторский или локальный IPTV multicast напрямую, не требуя обязательной установки udpxy.

Поддерживаемые адреса:

- `udp://@239.1.1.1:1234`
- `udp://239.1.1.1:1234`
- `rtp://@239.1.1.1:5000`
- `rtp://239.1.1.1:5000`

## Путь данных

1. Пользователь импортирует M3U либо вводит точный адрес потока.
2. Приложение проверяет, что адрес действительно multicast.
3. Выбирается активный Wi-Fi или Ethernet интерфейс с IPv4 и multicast support.
4. Получается Android `MulticastLock`.
5. Выполняется `joinGroup` для заданной группы и порта.
6. Для RTP разбирается заголовок v2, CSRC, extension и padding.
7. Извлекается MPEG-TS payload.
8. PAT, PMT и DVB-SDT используются для определения канала, провайдера и кодеков.
9. Для встроенного `VideoView` создаётся локальный HTTP MPEG-TS relay на `127.0.0.1`.
10. При закрытии плеера выполняются `leaveGroup`, освобождение lock и закрытие сокетов.

## Диагностика

Показываются:

- multicast group и порт;
- UDP или RTP;
- выбранный сетевой интерфейс;
- успешность IGMP join;
- число принятых пакетов;
- объём MPEG-TS;
- потери последовательности RTP;
- время до первого пакета;
- приблизительный bitrate;
- MPEG-TS sync;
- DVB service name/provider;
- video/audio codec.

## Когда нужен udpxy

udpxy остаётся полезен, если:

- Wi-Fi точка блокирует multicast;
- сеть не пропускает IGMP до телефона;
- Android-прошивка фильтрует UDP multicast;
- поток нужно преобразовать в обычный HTTP для нескольких клиентов;
- multicast доступен на другом сегменте сети.

## Безопасность

Модуль не перебирает весь диапазон 224.0.0.0/4. Он подключается только к адресам из разрешённого пользователем плейлиста, SAP/SDP либо ручного ввода. DRM, шифрование и аутентификация не обходятся.
