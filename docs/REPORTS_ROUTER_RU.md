# Этап 7: отчёты и API своих роутеров (beta20)

## Отчёты

«Данные → Отчёты»: разделы карточек, наблюдений сервисов, изменений, TCP-проверок и снимков API роутеров. Можно выбрать поля и CSV/JSON/HTML. Раздел, время и источник обязательны. MAC по умолчанию выключен. Источник относится к конкретной записи, а не ко всему устройству. Сохранённое подключение не объявляется проверенным сервисом; DHCP-аренда не означает, что клиент сейчас в сети.

Время в файлах — Unix milliseconds UTC. JSON schema=1: fields/sections, rows со строковыми значениями, startedAt/finishedAt, rowCount/truncated/shortenedValues. CSV — UTF-8 BOM, CRLF, кавычки и экранирование внутренних кавычек; последняя строка section=report_metadata содержит метаданные, не является измерением. HTML — самостоятельный файл с экранированными значениями и CSP без скриптов/внешних ресурсов.

Есть пределы 1000/10000/50000 строк и «Все» без предела строк. Превышение выбранного предела явно отмечается. Значения длиннее 4096 символов сокращаются с многоточием и счётчиком. Чтение базы по одной записи с ключевой пагинацией не удерживает целиком весь отчёт в памяти; формирование можно отменить. Это последовательное чтение сохранённых данных, не атомарный снимок базы. Изменения базы во время формирования могут отразиться в разных разделах в разное время; для восстановления используйте резервную копию.

Файл сначала полностью формируется во временном каталоге приложения; затем пользователь выбирает место через системный диалог. Отмена/уход с экрана останавливает формирование и удаляет его временный файл. При ошибке записи SAF-документа выбранный документ не удаляется автоматически: там мог существовать файл пользователя. Может остаться частичная запись; интерфейс сообщает об этом. После завершения процесса приложения незавершённый отчёт нужно сформировать заново.

## Исключение секретов

Экспорт использует разрешённый перечень полей. Не читает SecureStore, URI сохранённых подключений, баннеры, сырые ответы API, evidence, комментарии роутера, PSK и поля password/token. Неизвестные поля истории игнорируются. URL проходят удаление userinfo и известных секретных параметров; текстовые password/token/secret-назначения и Bearer дополнительно маскируются. У CSV потенциальные формулы с = + - @ в начале значения (в том числе после пробелов/управляющих символов) получают начальный апостроф. HTML экранирует &, <, > и кавычки.

Названия, модели, IP и выбранный MAC остаются данными отчёта. Произвольный секрет, который пользователь сам вписал как обычное название без метки, автоматически распознать нельзя. Перед передачей отчёта выбирайте нужные поля и проверяйте содержание.

## API своих роутеров

«Моя сеть → Роутеры». Требуются разрешение владельца, вручную указанный адрес API и его учётные данные. Нет поиска паролей, перебора, обхода авторизации или автоматического применения конфигурации. В этом выпуске адаптеры читают сведения; изменение настроек роутера — отдельный будущий этап.

RouterOS 7 REST: только GET /rest/system/identity, /rest/system/resource, /rest/interface, /rest/ip/dhcp-server/lease. Нужны включённый REST (www-ssl) и достаточные права API/чтения. HTTP Basic поверх HTTPS. Набор полей снимка: имя, производитель/модель/версия/uptime, имена/типы/состояние интерфейсов, адреса/MAC/имена/состояние DHCP-аренд. Первый ответ identity обязателен; отказы поддерживаемых необязательных операций обозначают частичный снимок.

OpenWrt: POST /ubus JSON-RPC с фиксированными вызовами session.login (таймаут сессии 60 с), system.board, system.info, network.interface.dump, dhcp.ipv4leases, session.destroy. Нужны rpcd, uhttpd-mod-ubus и ACL на перечисленные методы. DHCP читается из odhcpd device → имя интерфейса → leases; dnsmasq-only без такого метода отмечается как неподдерживаемый раздел, а не пустая подтверждённая сеть. Временный ubus-токен находится только в памяти, сессия уничтожается после чтения; при отмене/ошибке завершения истекает на сервере. Отдельный API-пользователь с минимальными правами предпочтителен.

HTTPS использует обычную проверку доверия Android и имени хоста. Самоподписанный сертификат без доверия не принимается; автоматического отключения TLS-проверки нет. HTTP допускается только после отдельного выбора и только для числового локального IP (loopback/link-local/private/ULA); домены и публичные IP отклоняются, чтобы не передавать данные входа открыто в интернет. HTTP не шифрует данные даже в LAN. Переадресации не выполняются, чтобы не передать авторизацию другому серверу.

Сеть выбирается существующим механизмом LAN/VPN маршрутов; запросы привязаны к выбранной сети. При отсутствии сети опрос не начинается. Нет автоматических повторов после отказа авторизации. Ответы ограничены 1 МиБ на запрос, нормализованные строки снимка — 512 КиБ, значения — 512 символов. Превышение бюджета строк отмечается как частичный снимок. Таймаут соединения/чтения до 6 с, общий бюджет около 30 с; системное DNS не всегда мгновенно отменяется. Отмена закрывает активное соединение; токены, пароли, тела ответов и детали исключений не используются как текст ошибки.

Сохраняются последние 20 снимков с временем, адаптером, сетью и отметкой полноты. Нет автоматического объединения DHCP-клиентов с карточками устройств: это ещё один источник, не доказательство одинакового оборудования. Удаление подключения удаляет его учётные данные, но сохраняет историю; история очищается отдельно с подтверждением. Если опрос уже завершился и сохранение началось, завершённый снимок может сохраниться одновременно с уходом с экрана.

Настройки подключения содержат только URL без пути/userinfo/query и метаданные. По отдельному выбору логин/пароль сохраняются одной AES-GCM записью Android Keystore. Они связаны с адресом и видом адаптера: восстановление/смена адреса не подставляет сохранённый пароль к другому узлу. Ошибка Keystore не включает открытое хранение. Без выбора «Запомнить» данные живут в состоянии экрана и теряются после его закрытия/пересоздания. Резервная копия v11 (SQLite v6) включает метаданные и нормализованные снимки, но не защищённое хранилище. Старые копии читаются, новые таблицы при их восстановлении очищаются. Некорректные контейнеры/поля проверяются до удаления существующих данных.

## Проверки

Локальные HTTP-фикстуры покрывают whitelist GET/RPC, Basic, login/logout, ACL/частичный снимок, маскирование известных секретов, неверный JSON, переадресации, большой ответ и отмену. Тесты БД проверяют миграции, границы истории, резервное восстановление и отказ без потери данных. Экспорт проверяется на JSON/CSV/HTML, обязательные/выбранные поля, формулы, разметку, секреты, отмену, сокращения и соответствие признака внешней TCP-доступности экрану.

Физический телефон, RouterOS и OpenWrt в этой сессии не подключены. Требуется прогон реальных прошивок/ACL, сертификатов, Wi-Fi/VPN, поворота/фона, больших списков DHCP и открытия всех трёх файлов через Android SAF. JVM-тесты не заменяют этот прогон.
