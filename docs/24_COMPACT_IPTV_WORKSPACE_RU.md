# Спецификация 24 — Compact IPTV Workspace

## Вкладки
### Каналы
Только просмотр и навигация по каталогу.

### Источники
Только загрузка и обнаружение источников.

### Диагностика
Только проверка качества и технические сведения.

## Правила компактности
- никаких постоянных многострочных полей M3U на экране каналов;
- никаких длинных URL в строке канала;
- одна строка канала является основной кнопкой просмотра;
- техническая карточка открывается отдельно;
- фильтры и поиск располагаются над плейлистом;
- инженерные логи не смешиваются с просмотром.

## Плеер
- собственные компактные контролы;
- автоскрытие;
- fullscreen;
- PiP;
- соседние каналы;
- внешний плеер;
- поддержка HTTP/udpxy и прямого UDP/RTP multicast.
